One funny single-line sport the Olympics turned down, written by
[`main.py`](main.py) to `/output/entry.txt`.

## The entry

> Synchronised queueing: four athletes stand in a perfectly straight line for six hours; gold goes to whoever complains the least.

128 characters — inside the 1–200 character gate, one line, no wasted words.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, no trailing newline). The gate is
validated in `main()` before anything is written: an invalid text exits
non-zero and writes no file.
